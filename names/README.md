# Bird names by language

These files give the common name of each bird in other languages, for the My Aviary Forest app.
The app downloads only the file for the player's language.

Source: IOC World Bird List (multilingual version), Gill, F., D. Donsker and P. Rasmussen (Eds),
[worldbirdnames.org](https://www.worldbirdnames.org), licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
Each file names the exact version it was built from.
